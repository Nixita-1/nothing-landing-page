#  Nothing Landing Page

A responsive product landing page built using **HTML**, **SCSS**, and **vanilla JavaScript** — bundled with **Parcel** for a smooth development and build experience.

---

##  Project Overview

This project is a modern, mobile-friendly landing page designed to showcase products in a clean and engaging layout. It demonstrates:

- ✅ Modular SCSS structure
- ✅ BEM methodology for class naming
- ✅ Mobile-first responsive design
- ✅ Contact form with basic validation
- ✅ Optimized asset handling (images, fonts)
- ✅ Built with Parcel bundler for zero-config development

---

## Tech Stack

- HTML5
- SCSS
- JavaScript (ES6+)
- Parcel (v2)
- Google Fonts

---

## 🛠 How to Run Locally

- npm install
- npm start

Or for production build run:

- npm run build
